# GenAI Prompts Used

This assignment explicitly allows using GenAI and other tools, but asks the candidate to document the prompts used. Below is the prompt log for this project.

## Prompt 1: Assignment Translation
I provided the programming assignment PDF and asked ChatGPT to translate the assignment requirements into Vietnamese so I could understand the task precisely.

## Prompt 2: Project Planning
I asked ChatGPT to help design a professional solution for the Elyx Resource Allocator assignment, including technology stack, project structure, data model, scheduler logic, hosting plan, README content, and submission strategy.

## Prompt 3: Implementation Guidance
I asked ChatGPT to help create a Python and Streamlit implementation with synthetic action-plan data, resource availability data, a constraint-aware scheduling algorithm, a readable calendar output, and detailed usage instructions.

## Prompt 4: Data Model Design
I asked ChatGPT to propose realistic JSON schemas for at least 100 activities and three months of availability data for client schedule, travel plans, equipment, specialists, and allied health professionals.

## Prompt 5: Scheduler Design
I asked ChatGPT to help design an explainable scheduler that prioritizes health activities and considers client availability, travel constraints, specialist availability, allied health availability, equipment availability, remote feasibility, backup activities, and skipped-activity adjustments.

## Prompt 6: Documentation and Deployment
I asked ChatGPT to help write professional documentation, local run instructions, Streamlit deployment instructions, project assumptions, limitations, and final submission guidance.

## Notes on AI Usage
GenAI was used for brainstorming, code structure, sample data generation strategy, documentation, and code review assistance. The final project was reviewed and adapted by the candidate before submission.
